1. 微PE简介与版本选择

1.1 什么是微PE

微PE工具箱（WePE）是一款基于 Windows PE 内核的便携式维护系统。它可以直接写入U盘，从U盘启动后形成一个独立的图形化操作环境，不依赖本机硬盘上的操作系统。其特点是体积小、启动快、界面接近 Windows、内置常用维护工具，且官方版本不捆绑广告与第三方软件。

微PE本身不是操作系统，不能长期日常使用；它的定位是"临时维护平台"，用于装系统、分区、修复引导、备份数据等场景。

1.2 适用场景

场景 说明
全新安装系统 硬盘为空或系统损坏时，从PE写入 Windows 镜像
系统无法启动 蓝屏、引导损坏、卡开机时进入PE排查
硬盘分区管理 新建/调整/合并分区，GPT 与 MBR 互转
引导修复 重建 BCD、修复 UEFI/BIOS 引导
密码重置 忘记本机登录密码时修改（仅限自有设备）
数据抢救 系统崩溃后把重要文件拷贝到移动硬盘
磁盘检测 查看硬盘健康、坏道、分区表状态

1.3 版本选择

微PE 2.x 提供 64 位与 32 位两种内核，并按功能分为维护版与网络版（不同版本命名可能为"标准版/增强版"，以官网下载页说明为准）。

对比项 64 位版 32 位版 维护版 网络版
适用机器 2010 年后主流机型，支持 UEFI 启动 老旧 32 位机型、部分老上网本 绝大多数维护场景 需要在PE内上网的场景
内存要求 建议 ≥2 GB 建议 ≥1 GB 较低 较高
内置工具 分区、备份、引导修复等全套 同左，工具略精简 分区/备份/修复工具 维护版工具 + 浏览器、网络组件
网络支持 视版本而定 视版本而定 无（或需手动加载网卡驱动） 内置有线/无线网卡驱动与浏览器
体积 中等 较小 较小，启动快 较大，启动稍慢
推荐人群 首选 仅老机器使用 装系统、修电脑为主 需要联网查资料、下载驱动

选择建议：

  1. 能启动 64 位系统的新机器，一律选 64 位版；只有确认机器仅支持 32 位时才用 32 位版。
  2. 以装系统、分区、修引导为主，选维护版即可，启动更快、兼容性更稳。
  3. 经常遇到"PE 里没网卡驱动、需要现场下载驱动"的情况，选网络版。
  4. 只从官网（wepe.com.cn）或官方发布渠道下载，避免第三方"修改版"捆绑软件。

2. 制作启动U盘

2.1 准备工作：U盘容量与格式要求

项目 要求
U盘容量 至少 8 GB，推荐 16 GB 及以上（64 位网络版体积更大）
U盘接口 USB 2.0/3.0 均可；老机器优先用 USB 2.0 接口，兼容性更好
U盘状态 能被系统正常识别，无坏块；制作会清空全部数据
文件系统 由官方工具自动格式化，通常为 exFAT；也可在工具内选 FAT32 或 NTFS
镜像文件 官方安装程序（.exe），无需提前解压

格式差异说明：

  • exFAT：支持大于 4 GB 的单文件，兼容 UEFI 与 Legacy，官方默认选项，推荐保持默认。
  • FAT32：UEFI 兼容性最好，但单文件不能超过 4 GB（放大于 4 GB 的系统镜像会失败）。
  • NTFS：支持大文件，部分老主板 UEFI 不识别，非必要不选。

2.2 官方工具制作步骤

  1. 准备一个没有重要数据的U盘，插入电脑（建议插在机箱后置 USB 接口）。
  2. 关闭杀毒软件的实时防护（部分安全软件会拦截写入引导扇区），制作完成后重新开启。
  3. 右键官方安装程序，选择"以管理员身份运行"。
  4. 在主界面选择"安装PE到U盘"（部分版本显示为U盘图标）。
  5. 在"待写入U盘"下拉框中确认目标盘符与容量，务必核对，避免误写移动硬盘。
  6. 选择文件系统（建议默认 exFAT）与卷标，保持"支持UEFI启动"等默认勾选。
  7. 点击"立即安装进U盘"，在确认提示中核对U盘信息后确认。
  8. 等待写入完成（通常 1–5 分钟，取决于U盘速度），提示"制作完成"后关闭工具。
  9. 安全弹出U盘，重新插入，确认能看到U盘分区及其中文件。

若工具提供"双分区方案/单分区方案"选项：双分区会额外创建一个隐藏的 EFI 启动分区，兼容性更好；单分区结构简单、可见容量更大。普通用户保持默认即可。

2.3 制作后U盘容量变化说明

制作完成后发现U盘"变小了"，属于正常现象，原因有三：

  1. 标称容量与系统显示差异：厂商按 1 GB = 1000 MB 标称，系统按 1 GB = 1024 MB 计算，32 GB U盘在系统中通常显示约 29–30 GB。
  2. PE 文件占用：PE 系统及内置工具会占用约 0.5–1 GB 空间（网络版更多）。
  3. 隐藏分区：双分区方案会创建一个隐藏的 EFI 启动分区（数百 MB），在资源管理器中不可见。

因此，32 GB U盘制作后显示 28–29 GB 可用空间是正常的。若需恢复U盘全部容量：

  1. 打开 Windows"磁盘管理"或PE中的 DiskGenius；
  2. 删除U盘上的全部分区（注意核对磁盘编号，避免误删硬盘）；
  3. 重新新建一个分区并格式化。

2.4 注意事项

  • 制作会清空U盘全部数据，操作前先备份。
  • 不要中途拔出U盘或断电，否则U盘可能变为"未格式化"状态，需重新制作。
  • U盘制作完成后仍可作为普通U盘存放文件，但不要删除根目录下的 PE 相关文件与隐藏分区。
  • 部分品牌主板对U盘启动兼容性差，可尝试更换 USB 2.0 接口或更换U盘。
  • 建议保留一份PE安装程序，便于U盘损坏后重新制作。

3. 进入PE

3.1 BIOS/UEFI 启动项快捷键对照表

开机时反复按"启动菜单键"可直接选择从U盘启动；按"BIOS设置键"则进入固件设置界面调整启动顺序。

品牌 启动菜单键（Boot Menu） BIOS/UEFI 设置键 备注
华硕 ASUS F8 Del / F2 部分笔记本为 Esc
联想 Lenovo F12 F2 或 Fn+F2 部分机型用侧边 Novo 小孔，选择"Boot Menu"
戴尔 Dell F12 F2 部分机型 F12 菜单内含 BIOS Setup
惠普 HP F9 Esc → F10 部分商用机 F10 直接进 BIOS
微星 MSI F11 Del 台式机主板常见
技嘉 Gigabyte F12 Del 部分主板 F12 为启动菜单
华擎 ASRock F11 Del / F2 —
宏碁 Acer F12 F2 需在 BIOS 中开启 F12 启动菜单
神舟 Hasee F7 或 F12 F2 机型差异较大
三星 Samsung F12 / F10 F2 —
东芝 Toshiba F12 F2 —
微软 Surface 音量减 + 电源键 音量加 + 电源键 需在 UEFI 中关闭 Secure Boot

操作要点：

  1. 插入制作好的U盘，重启电脑。
  2. 开机出现品牌 Logo 时连续轻按对应按键（不要长按）。
  3. 在启动菜单中选择U盘名称（通常显示为 "UEFI: 品牌名" 或 "USB HDD"）。
  4. 若列表中没有U盘，进入 BIOS 检查U盘是否被识别、是否开启 Legacy/CSM。

3.2 Secure Boot 与 UEFI/Legacy 设置

设置项 位置（常见） 建议值 说明
Secure Boot（安全启动） Security / Boot 选项卡 Disabled（关闭） 开启时可能拒绝非签名引导，导致U盘无法启动
UEFI/Legacy Boot Boot 选项卡 与安装方式匹配 UEFI+GPT 选 UEFI；Legacy+MBR 选 Legacy
CSM（兼容支持模块） Boot 选项卡 装 Legacy 系统时 Enabled 装 UEFI 系统时可 Disabled
Fast Boot（快速启动） Boot 选项卡 Disabled（临时） 关闭后更容易捕捉按键、识别U盘
SATA 模式 Storage / Advanced AHCI（除非原系统为 RAID） 改动可能导致已装系统蓝屏，需谨慎

设置原则：

  • 新机器（2013 年后）：保持 UEFI 启动，关闭 Secure Boot，用 GPT 分区安装 64 位系统。
  • 老机器：切换为 Legacy（开启 CSM），用 MBR 分区安装。
  • 修改 Secure Boot 前若设置了 BIOS 密码，需先输入密码；部分品牌需先设置管理员密码才能修改。

3.3 WinPE 启动菜单选项说明

从U盘启动后会先出现 PE 引导菜单，常见选项如下（不同版本文字略有差异）：

菜单项 作用 使用建议
启动微PE工具箱（默认） 以标准分辨率进入PE桌面 首选
兼容模式 / 低分辨率模式 使用基础显卡驱动进入 花屏、黑屏、无法显示桌面时选择
从本机硬盘启动 跳过PE，直接引导本机系统 临时不想进PE时使用
重启 / 关机 重启或关闭电脑 —

进入桌面后，若分辨率异常，可在桌面右键"显示设置"调整，或重启选择兼容模式。

PE 桌面通常包含以下工具（开始菜单或桌面图标进入）。不同版本可能多一个或少一个，以实际界面为准。

4.1 DiskGenius：分区与 GPT/MBR 转换

新建分区（以 GPT 为例）：

  1. 打开 DiskGenius，在左侧选择目标硬盘（务必核对容量与型号）。
  2. 点击"磁盘" → "转换分区表类型为GUID格式"（若已是 GPT 可跳过）。
  3. 点击"保存更改"。
  4. 选中硬盘，点击"分区" → "新建分区"，依次创建：
    • ESP 分区：约 300 MB，文件系统 FAT32（UEFI 启动必需）；
    • MSR 分区：约 16 MB（可选，Windows 安装程序通常会自动创建）；
    • 系统分区 C：剩余空间，NTFS。
  5. 再次点击"保存更改"，等待格式化完成。

GPT 与 MBR 互转：

  1. 选中目标磁盘；
  2. 点击"磁盘" → "转换分区表类型为MBR格式"（或"为GUID格式"）；
  3. 确认警告并"保存更改"。

转换分区表类型可能影响原有引导与分区识别，操作前必须备份数据；已有系统的磁盘转换后通常需要重新修复引导。

数据恢复：

选中丢失数据的分区 → "工具" → "已删除或格式化后的文件恢复" → 选择恢复方式 → 扫描 → 勾选文件 → 复制到另一块磁盘（不要恢复到原盘）。

4.2 分区助手

分区助手适合做"无损调整"，操作比 DiskGenius 更直观：

  1. 选中分区，右键选择"调整/移动分区"，拖动边界或输入新容量；
  2. 点击左上角"提交"执行变更；
  3. 合并分区：右键分区 → "合并分区"，选择要合并的相邻分区；
  4. 克隆磁盘：使用"克隆磁盘"向导，把旧盘完整复制到新盘（目标盘容量需不小于源盘已用空间）。

调整系统分区前建议先备份；操作过程中不要断电。

4.3 Windows 密码修改

适用于自有设备忘记本机账户密码的情况。工具通常为 NTPWEdit 类程序：

  1. 打开"Windows 密码修改"工具；
  2. 点击"打开"，定位到目标系统的 SAM 文件：
    C:\Windows\System32\config\SAM
    （若系统装在 D 盘，则相应改为 D:\Windows\System32\config\SAM）；
  3. 在用户列表中选择要修改的账户；
  4. 点击"更改密码"，留空表示清除密码，或输入新密码；
  5. 点击"保存"，重启电脑。

注意事项：

  • 仅对本地账户有效；微软账户在线密码不适用。
  • 若系统启用了 BitLocker，修改密码后可能仍无法进入，需先恢复密钥解锁。
  • 本操作仅限自有设备，不得用于他人设备。

4.4 引导修复（BCD）

方式一：图形化引导修复工具

  1. 打开"引导修复"（部分版本为 NTBOOT 引导修复）；
  2. 工具会自动识别硬盘上的 Windows 系统；
  3. 点击"开始修复"/"自动修复"，等待完成；
  4. 重启验证。

方式二：Dism++ 引导修复

打开 Dism++ → 菜单"恢复功能" → "引导修复" → 选择系统盘 → 确定。

方式三：命令行 bcdboot（最可靠）

  1. 打开命令提示符；
  2. 确认系统盘符（PE 下盘符可能与正常系统不同，用 dir C:\Windows 逐个核对）；
  3. 确认 EFI 分区盘符（可在 DiskGenius 中给 ESP 分区分配盘符，如 S:）；
  4. 执行：
:: UEFI + GPT 环境
bcdboot C:\Windows /s S: /f UEFI

:: Legacy + MBR 环境
bcdboot C:\Windows /s C: /f BIOS
  1. 提示"已成功创建启动文件"即完成。

4.5 WinNTSetup / Dism++ / Ghost 安装系统

WinNTSetup（推荐，支持 WIM/ESD/SWM）：

  1. 打开 WinNTSetup；
  2. "选择包含Windows安装文件的文件夹"：定位到挂载后的 ISO 中 sources\install.wim（或 install.esd）；
  3. 选择要安装的系统版本（如 Windows 10 专业版）；
  4. "选择引导驱动器"：
    • UEFI+GPT：选择 ESP 分区；
    • Legacy+MBR：选择系统分区 C；
  5. "安装磁盘的位置"：选择系统分区 C；
  6. 选项中可以勾选"格式化"（全新安装建议勾选）、"添加驱动"（如 VMD 驱动）；
  7. 点击"开始安装" → 确认 → 等待映像应用完成；
  8. 提示完成后重启，按提示拔掉U盘。

Dism++：

  1. 打开 Dism++，接受许可；
  2. 菜单"文件" → "释放映像"；
  3. 选择 install.wim 与目标分区 C；
  4. 勾选"添加引导"（UEFI 环境需正确识别 ESP）；
  5. 确定并等待完成。

Ghost（仅用于 .gho 镜像）：

  1. 打开 Ghost，选择 Local → Partition → From Image；
  2. 选择 .gho 文件；
  3. 选择目标硬盘与目标分区；
  4. 确认覆盖后等待完成，重启。

建议优先使用微软原版 ISO + WinNTSetup/Dism++，Ghost 镜像来源复杂，存在捆绑与安全风险。

4.6 驱动与网卡

  • 存储驱动（重要）：Intel 11 代及以后的平台若开启 VMD，PE 可能看不到 NVMe 硬盘，需加载 Intel VMD/IRST 驱动（详见第 7 章）。
  • 网卡驱动：维护版通常不含网卡驱动。可在PE中使用"驱动安装"工具，指定提前下载好的网卡驱动文件夹（.inf）进行安装；或直接使用网络版PE。
  • 驱动来源：优先从主板/笔记本厂商官网下载对应型号的驱动，避免使用来源不明的"万能驱动"。

4.7 截图与文件拷贝

  • 截图：打开"截图工具"，框选区域后保存到U盘或本地磁盘；部分版本支持快捷键（以工具界面提示为准）。
  • 文件拷贝：通过"资源管理器"或"Everything"定位文件，复制到移动硬盘。系统盘中的重要文件建议优先拷贝到另一块物理磁盘，不要存回原盘。
  • 只读挂载：若担心误改原系统文件，可先以只读方式浏览，确认后再复制。

5. 全新安装 Windows 完整流程

5.2 分步操作

  1. 备份数据：把桌面、文档、浏览器书签、微信/QQ 记录、驱动安装包等拷贝到移动硬盘或网盘。装系统会清空系统盘。
  2. 制作启动U盘：按第 2 章步骤完成，确认U盘可启动。
  3. 准备系统镜像：从微软官网或合法渠道下载原版 ISO，记录版本与位数；可用校验工具核对 SHA-256。
  4. 进入PE：按第 3 章方法从U盘启动，进入PE桌面。
  5. 确认硬盘：打开 DiskGenius，确认能看到目标硬盘及容量。若看不到，先解决驱动问题（见第 7 章），不要继续分区。
  6. 备份原分区表（可选）：DiskGenius → "磁盘" → "备份分区表"，保存到U盘。
  7. 分区：
    • UEFI 方案：GPT + ESP（FAT32，约 300 MB）+ 系统分区（NTFS）；
    • Legacy 方案：MBR + 活动主分区（NTFS）。
  8. 挂载 ISO：在资源管理器中右键 ISO 文件 → "装载"（Win10 内核 PE 支持）；若无法装载，可用PE内置虚拟光驱工具，或把 ISO 解压到硬盘非系统分区。
  9. 写入系统：打开 WinNTSetup，按 4.5 节选择 install.wim、引导驱动器、安装磁盘，开始安装。
  10. 确认引导：WinNTSetup 通常会自动写入引导；如未勾选，安装完成后用 bcdboot 或引导修复工具补做。
  11. 重启：安装完成后选择重启，在重启时拔出U盘（或进 BIOS 把硬盘设为第一启动项），避免再次进入PE。
  12. 首次配置：进入 Windows OOBE，选择区域、键盘、网络、账户，完成初始化；进入桌面后安装驱动与常用软件。

5.3 UEFI+GPT 与 Legacy+MBR 的选择

对比项 UEFI + GPT Legacy + MBR
适用机器 2013 年后主流机型 老旧机型、部分工控设备
系统位数 必须 64 位 32/64 位均可
磁盘容量 支持 >2 TB 系统盘 系统盘受 2 TB 限制
分区数量 基本无限制（Windows 限制 128 个） 最多 4 个主分区
启动速度 较快 较慢
Secure Boot 可配合使用 不支持
引导分区 需要 ESP（FAT32） 需要活动主分区
推荐度 新机首选 仅老机使用

选择原则：

  1. 启动方式与分区表必须匹配：UEFI 启动配 GPT，Legacy 启动配 MBR。混用会导致"装完无法引导"。
  2. 不确定时，进入 BIOS 查看当前是 UEFI 还是 Legacy；新机器保持 UEFI。
  3. 若硬盘已有 GPT 分区且要装 Legacy 系统，需先转换为 MBR（会清空分区，先备份）。
  4. 大于 2 TB 的硬盘做系统盘，必须使用 GPT。

7.1 PE 中看不到硬盘（Intel VMD/IRST）

这是新平台最常见的问题。Intel 11 代及以后的处理器默认开启 VMD（Volume Management Device），普通 PE 缺少对应驱动时无法识别 NVMe 硬盘。

处理方式二选一：

  1. BIOS 关闭 VMD：进入 BIOS → Advanced/Configuration → VMD Setup Menu → 将 VMD Controller 设为 Disabled，或把 SATA/NVMe 模式改为 AHCI；保存后重新进入PE。
    • 注意：若原系统是在 VMD/RAID 模式下安装的，直接改 AHCI 可能导致原系统蓝屏，需先在系统中调整或重装。
  2. 在PE中加载 VMD 驱动：提前从主板/笔记本厂商官网下载 Intel RST/VMD 驱动（包含 iaStorVD.inf 等文件），在PE中用"驱动安装"工具或 Dism++ 注入后重新扫描磁盘。

7.2 装完系统无引导

按以下顺序排查：

  1. 确认 BIOS 启动模式（UEFI/Legacy）与分区表（GPT/MBR）一致；
  2. UEFI 环境确认 ESP 分区存在且为 FAT32，内有 EFI\Microsoft\Boot\bootmgfw.efi；
  3. 进入PE执行 bcdboot C:\Windows /s S: /f UEFI（S 为 ESP 盘符）；
  4. 检查 BIOS 启动顺序，把 "Windows Boot Manager" 或硬盘设为第一项；
  5. 若仍失败，检查硬盘是否为 GPT 且存在 MSR/ESP 分区，必要时重新分区安装。

7.3 蓝屏与驱动冲突

  • 记录蓝屏代码（如 INACCESSIBLE_BOOT_DEVICE 多为存储驱动/模式问题）；
  • 确认 BIOS 的 SATA 模式与安装时一致（AHCI/RAID 不要随意切换）；
  • 使用原版镜像并校验完整性；
  • 拔掉多余外设与内存条逐一排查硬件。

8. 合规与安全提示

  1. 仅用于自有设备：本教程涉及的密码修改、分区、重装等操作，仅可在自己拥有或已获得明确授权的设备上进行，严禁用于他人设备。
  2. 系统镜像来源合法：请使用微软官方或已获授权的镜像，不要使用来源不明的"精简版/破解版"系统，此类镜像可能捆绑恶意程序。
  3. 重要数据先备份：分区、转换分区表、重装系统均可能导致数据丢失，操作前必须完成备份。
