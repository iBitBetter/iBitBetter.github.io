*01 · Executive Summary*

## 执行摘要

C 盘变红通常不是硬盘太小，而是**空间被放在了不该放的地方**。这份手册把清理拆成五轮：前两轮不需要任何专业知识，也不可能删坏系统；后三轮涉及命令行和系统组件，每一步都写清代价。按顺序做，做完一轮再决定要不要做下一轮。

### 核心要点

- **前两轮足以解决多数人的问题。**清掉自家文件和系统自带清理项，多数机器能腾出 3GB 到 20GB，全程不需要管理员权限之外的操作。
- **四项系统文件常占 10GB 以上。**休眠文件、虚拟内存、系统还原点、Windows.old，正确做法是转移或限容，不是一刀切删除。
- **WinSxS 只走官方路径。**组件库手动删除会导致更新失败，只能用 DISM 命令或 Dism++ 的组件清理处理。
- **不反弹靠三个默认路径。**下载文件夹、聊天软件文件目录、新软件安装位置，改一次设置，长期有效。

> **本文档回答的问题**
>
> 我的 C 盘空间被什么吃掉了？不重装系统最多能安全腾出多少空间？哪些看起来省事的操作，实际上会把系统搞坏？

*02 · Diagnosis*

## 第一步：先看清空间去哪了

清理失败最常见的原因不是胆子小，而是动手太早。先花十分钟看清空间分布，后面每一步都能有的放矢。

### 先记下一个基准数字

打开「此电脑」，右键 C 盘选「属性」，记下已用和可用空间。这个数字要记下来，全部做完后再看一次，才知道到底省了多少。刚装完系统的 Win10 和 Win11 通常占 30GB 到 50GB，Win7 约 20GB 到 30GB，明显超出这个范围的部分，就是可以处理的对象。

### 用方块图看清谁最大

接着装一个磁盘占用可视化工具。WinDirStat 是开源软件（GPL v2），安装包不到 1MB，启动后勾选 C 盘、等扫描完成，它会用方块面积画出每个文件夹的体积：方块越大，占得越多。WizTree 读取 NTFS 索引，扫描快得多，但它免费不开源，介意授权方式就用 WinDirStat。

| 工具 | 授权 | 特点 | 适合谁 |
| --- | --- | --- | --- |
| WinDirStat | 开源 GPL v2 | 扫描较慢，界面朴素，方块图直观 | 只装开源软件的用户 |
| WizTree | 免费，非开源 | 读 NTFS 主文件表，机械硬盘也能秒扫 | 想快速看结果 |
| SpaceSniffer | 免费，非开源 | 边扫边显示，可逐层下钻 | 喜欢层级浏览 |

### 只看三处，只看不删

扫完后重点看三处：C:\Users\你的用户名、C:\Windows、C:\Program Files 与 C:\ProgramData。前者是你的文件与聊天记录，中间是系统与更新残留，后者是已安装软件。在 WinDirStat 里双击方块能直接跳到资源管理器并选中文件，但这一步只看不删，删除动作留到后面按顺序做。

*03 · Round One*

## 第一轮：可以放心删的自家文件

这一轮不需要任何工具，也不可能删坏系统，因为对象全部是你自己产生的数据。经验上，回收站、下载文件夹、桌面大文件和聊天缓存这四处，往往就能解决一半以上的空间问题。

### 一、回收站

回收站是最容易被忽略的地方。在桌面右键回收站选「清空回收站」，几十 GB 的视频和旧安装包常常就躺在这里。清空之前可以先打开看一眼，确认没有还想找回的文件，因为这一步不可撤销。

### 二、下载文件夹与桌面

打开下载文件夹（三个版本的路径都是 C:\Users\你的用户名\Downloads），在空白处右键选「排序方式 → 大小」，让最大的文件排在最前面。装完软件后残留的安装包（.exe、.msi、.iso）基本没用了，可以直接删；桌面常被当成临时存放区，把大文件拖到 D 盘或移动硬盘，比删掉更安全。

### 三、微信与 QQ 的聊天文件

微信和 QQ 的聊天文件默认存在 C 盘，几年下来能到几十 GB。微信左下角「设置 → 文件管理 → 打开文件夹」可以查看占用，同一页面提供「更改」按钮，把存储路径换到别的盘；QQ 在「设置 → 基本设置 → 文件管理」里同理。清理时只删 FileStorage 里的视频和图片缓存，不要动数据库文件和 Msg 目录，否则聊天记录会丢失。

> 判断一个文件夹能不能删，最简单的标准是：删掉之后，你有没有能力重新生成它。安装包可以重新下载，缓存可以重新产生，聊天数据库不能。

### 四、浏览器缓存

Edge 在「设置 → 隐私、搜索和服务 → 清除浏览数据」里，勾选「缓存的图像和文件」，时间范围选「所有时间」，不要勾选密码和自动填充。Chrome 在「设置 → 隐私和安全 → 删除浏览数据」，操作相同。这一步通常能腾出 1GB 到 5GB，代价只是第一次打开网页稍慢。

*04 · Round Two*

## 第二轮：系统自带的一键清理

磁盘清理和存储感知是唯一由微软定义了安全边界的清理入口，勾选项背后都有明确的系统语义。三个版本的入口位置不同，可勾选的内容却基本一致。

### Windows 7：磁盘清理 + 清理系统文件

Win7 依次点「开始 → 所有程序 → 附件 → 系统工具 → 磁盘清理」，或者在「计算机」里右键 C 盘选「属性 → 磁盘清理」。进入后先点下方的「清理系统文件」按钮，重新扫描一遍，会多出「Windows 更新清理」和「以前的 Windows 安装」两个大项。这两项动辄上 GB，是 Win7 最值得清理的内容。

### Windows 10：存储感知

Win10 打开「设置 → 系统 → 存储」，页面顶部会显示各分类占用。点「临时文件」进入勾选界面，勾上「临时文件」「传递优化文件」「缩略图」，需要的话再勾「以前的 Windows 安装」，然后点「删除文件」。同一页面的「存储感知」开关建议打开，设定为每月自动清理一次，之后就不用再手动管。

### Windows 11：清理建议

Win11 的路径是「设置 → 系统 → 存储 → 清理建议」，系统会直接把可清理项按占用大小排好，逐条点「清理」即可，比手动勾选更省事。Win11 仍然保留了传统的磁盘清理：按 Win+R 输入 cleanmgr 回车就能打开，功能与 Win10 一致。

| 功能 | Windows 7 | Windows 10 | Windows 11 |
| --- | --- | --- | --- |
| 图形清理入口 | 附件 → 系统工具 → 磁盘清理 | 设置 → 系统 → 存储 → 临时文件 | 设置 → 系统 → 存储 → 清理建议 |
| 自动清理 | 无 | 存储感知 | 存储感知 |
| 更新残留 | 磁盘清理 → 清理系统文件 | 临时文件 → Windows 更新清理 | 清理建议自动列出 |
| 命令入口 | Win+R 输入 cleanmgr，三个版本通用 | — | — |

### 勾选时注意一件事

列表里有一项叫「下载」，勾上会把整个下载文件夹清空，包括你还没整理的文件，除非你确定下载夹里都是垃圾，否则不要勾。其余项目如「临时文件」「缩略图」「Windows 更新清理」「传递优化文件」都可以放心勾选。

*05 · Round Three*

## 第三轮：卸载与搬家

C 盘里的软件和用户文件夹是可以搬走的。搬一次省下的空间长期有效，而且不必担心下一次系统更新把它占回来。

### 先按大小卸载

Win10 和 Win11 打开「设置 → 应用 → 已安装的应用」，把右上角的排序方式改成「大小」，从最大的开始看。Win7 打开「控制面板 → 程序和功能」，点「大小」列排序。游戏、视频剪辑、设计类软件往往是头号占用者，不常用的直接卸载，比任何清理工具都有效。

### 让新软件默认装到 D 盘

Win10 和 Win11 在「设置 → 系统 → 存储 → 高级存储设置 → 保存新内容的地方」里，把「新的应用将保存到」「新的文档将保存到」等下拉框全部改成 D 盘。Win7 没有这个总开关，只能在安装软件时手动把路径里的 C 改成 D，安装向导里通常有「自定义安装」选项。Steam 等游戏平台可以在「设置 → 存储」里添加 D 盘库文件夹，再把已有游戏迁移过去。

### 把用户文件夹整体搬到 D 盘

文档、图片、视频、下载这四个文件夹可以整体迁移，既省空间又不改变使用习惯。做法是右键文件夹选「属性 → 位置 → 移动」，选一个 D 盘上的目标目录，确认后系统会询问是否移动现有文件，选「是」。三个版本的操作基本一致，唯一区别是 Win7 的文件夹需要先在资源管理器左侧的「库」里找到，才能看到「位置」选项卡。

> 搬家的顺序建议：先卸载、再搬软件、最后搬用户文件夹。反过来的话，移动过程中容易把正在运行的程序文件锁住，出现「文件正在使用」的报错。

*06 · Round Four*

## 第四轮：系统级空间回收

休眠文件、虚拟内存分页文件、系统还原点和 Windows.old，这四样东西经常悄悄占掉 10GB 以上。它们都有实际用途，所以做法是转移或限制，而不是简单删除。

### 一、休眠文件 hiberfil.sys

这个文件的大小在 Win7 上约等于物理内存，在 Win10 和 Win11 上约为内存的 40%，16GB 内存的机器就是 6GB 左右。关闭方法是以管理员身份打开命令提示符，输入 powercfg -h off 后回车，文件会立即消失。代价是不能再用「休眠」，Win10 和 Win11 还会同时失去「快速启动」，开机会慢几秒。想要回退，执行 powercfg -h on 即可。

### 二、虚拟内存分页文件

分页文件 pagefile.sys 默认也在 C 盘，大小常在 2GB 到 16GB。正确的做法不是关闭它，而是把它挪到别的盘：右键「此电脑」选「属性 → 高级系统设置 → 性能设置 → 高级 → 虚拟内存更改」，取消勾选「自动管理」，先选中 C 盘设为「自定义大小」，初始值和最大值都填 1024，再选中 D 盘设为「系统管理的大小」，确定后重启。保留 C 盘 1GB 是为了系统崩溃时还能写出转储文件，直接设成「无分页文件」会让蓝屏信息无法保存。

### 三、系统还原点

还原点默认最多可占用 C 盘的 10%，配置多了也是几个 GB。在开始菜单搜索「创建还原点」，选中 C 盘点「配置」，把「最大使用量」拉到 5% 左右即可，既保留了回滚能力，也不会无限膨胀。要一次性清掉旧还原点，用磁盘清理的「其他选项」标签页，在「系统还原和卷影复制」处点「清理」。

### 四、Windows.old

系统升级后会自动生成 Windows.old，把整个旧系统备份下来，体积通常 10GB 到 20GB，保留期 10 天，超时自动删除。想提前删掉，用「磁盘清理 → 清理系统文件」勾选「以前的 Windows 安装」，或者在「设置 → 系统 → 存储 → 临时文件」里勾选同名项目。删掉之后就回不到升级前的版本了，如果新系统用着没有异常，可以放心删。

> 这四项做完通常能回收 10GB 到 30GB，但每一项都在削减系统的容错能力。如果 C 盘只是略满，建议只做第一项和第三项，把虚拟内存和 Windows.old 留作后手。

*07 · Round Five*

## 第五轮：更新残留与 WinSxS

Windows 每装一次更新，都会在 WinSxS 留下旧组件。这是 C 盘里最容易被误删、也最容易被第三方工具「清理」坏的地方，正确做法只有两条：官方 DISM 命令，或 Dism++ 的图形界面。

### 为什么不能手动删

WinSxS 位于 C:\Windows\WinSxS，看起来很大，但其中大量文件是指向系统其他位置的硬链接，实际占用远小于资源管理器显示的数字。手动删除其中任何一个子目录，都可能导致系统更新失败、功能组件损坏，甚至无法开机。这个目录只应该由系统自己的组件服务来整理。

### 官方方式：DISM 命令

以管理员身份打开命令提示符，先执行 Dism.exe /Online /Cleanup-Image /AnalyzeComponentStore 查看可回收空间，再执行 Dism.exe /Online /Cleanup-Image /StartComponentCleanup 进行清理。加上 /ResetBase 参数会清得更彻底，但代价是已安装的更新再也无法卸载，系统出问题时不能单独回退某个补丁。这条命令从 Windows 8 才开始支持，Win7 请改用磁盘清理里的「Windows 更新清理」，前提是已安装 KB2852386 补丁。

### 图形方式：Dism++

Dism++ 由初雨团队开发，免费使用，项目主页在 GitHub 的 Chuyu-Team/Dism-Multi-language，支持从 Win7 到 Win11 的全部版本，绿色免安装，下载解压后右键以管理员身份运行。左侧点「空间回收」，勾选「临时文件」「Windows 更新清理」「系统日志」「缩略图缓存」，点「扫描」看能腾出多少，确认后点「清理」。整个过程三到五分钟，适合不想敲命令的用户。

| 手段 | 适用版本 | 可回收内容 | 风险 |
| --- | --- | --- | --- |
| 磁盘清理 → 清理系统文件 | 7 / 10 / 11 | 更新残留、旧系统备份 | 低 |
| DISM StartComponentCleanup | 8 / 10 / 11 | WinSxS 中已替代的组件 | 低到中 |
| DISM 加 /ResetBase | 8 / 10 / 11 | 同上，更彻底 | 中，更新不可卸载 |
| Dism++ 空间回收 | 7 / 10 / 11 | 临时文件、更新清理、日志 | 低到中，勾选项决定 |

*08 · Tools & Upkeep*

## 开源工具与日常维护

BleachBit 是少数值得信任的开源清理工具，但它默认勾选的选项里有几个对普通用户并不合适。工具只能解决一次性问题，想让 C 盘不再变红，靠的是三个默认路径的设置。

### BleachBit 怎么用

BleachBit 是 GPL v3 开源软件，官网 bleachbit.org，源码在 GitHub 的 bleachbit/bleachbit，Windows 版有标准安装包。安装后右键以管理员身份运行，在左侧列表里只勾这几类：系统下的「临时文件」和「日志」，应用下的浏览器缓存（Chrome、Edge、Firefox 各自的 cache 项）。勾完先点「预览」，看清它将删除哪些文件，确认无误再点「删除」。第一次使用建议先只清理浏览器缓存，熟悉流程后再扩大范围。

### 三个不要勾的选项

第一是「可用磁盘空间」（Free disk space），它会反复覆写整块空闲区域，机械硬盘上可能跑几个小时，收益却只是让已删文件不可恢复；第二是「内存」（Memory），清理时会强行结束正在运行的程序；第三是各应用下的「密码」「Cookie」类选项，清掉之后所有网站都要重新登录。BleachBit 还提供注册表清理，但对普通用户来说收益极小、误删风险不小，不建议使用。

### 不反弹靠三个设置

把「保存新内容的地方」全部指向 D 盘；把微信和 QQ 的文件目录改到 D 盘；装软件时养成改安装路径的习惯。再打开存储感知，设为每月自动清理临时文件与回收站。做到这四条，半年内基本不用再为 C 盘发愁，也就没必要反复用清理工具。

### 最后做一次验收

回到「此电脑」右键 C 盘看属性，和第一步记下的数字对比。如果释放的空间远小于扫描工具预估的数字，通常有两个原因：一是 WinSxS 的硬链接让估算偏大，实际可用空间才是准的；二是部分清理项需要重启后才真正释放。另外，固态硬盘建议长期保留 10% 到 15% 的可用空间，低于这个比例，写入性能和寿命都会受影响。

*09 · Pitfalls*

## 不要做的六件事

以下操作在网上流传很广，看起来能立刻省下几个 GB，代价却可能是系统更新失败、软件无法卸载，甚至无法开机。

1. **手动删除 C:\Windows\WinSxS。**这是组件库，删掉后系统更新和功能安装会直接失败，严重时需要重装。
2. **清空 C:\Windows\Installer。**里面是已安装软件的卸载与修复信息，删掉后这些软件既不能卸载也不能更新，还会反复提示「找不到安装包」。
3. **用注册表清理工具。**它能省下的空间以 MB 计，误删却可能导致软件无法启动。收益和风险完全不成比例。
4. **把虚拟内存设为「无分页文件」。**物理内存不够时程序会直接崩溃，蓝屏也无法生成转储文件。
5. **直接用命令删除 hiberfil.sys 文件。**系统会重新生成它，正确做法是用 powercfg -h off 关闭休眠功能。
6. **安装来源不明的「一键清理大师」「C 盘瘦身神器」。**这类工具常带捆绑安装和弹窗广告，部分还会改动浏览器主页。

还有一类操作需要额外提醒：删除 System Volume Information 文件夹、或用第三方工具强行清空「系统保护」。这个目录存放的是还原点，删除本身不违法，但等于放弃了系统出问题时的回滚能力，建议只在磁盘极度紧张、且已经做过完整备份的情况下才考虑。

如果你只想记住一句话：凡是位于 C:\Windows 下、名字里带 WinSxS、Installer、System32 的目录，都不要手动去删。清理系统文件的正确入口永远是磁盘清理、存储感知、DISM 和 Dism++ 这四个，它们知道哪些文件可以动。

### B. 命令清单

全部命令都需要以管理员身份运行命令提示符。关闭休眠是 powercfg -h off，恢复是 powercfg -h on；查看组件库占用是 Dism.exe /Online /Cleanup-Image /AnalyzeComponentStore，清理是加 /StartComponentCleanup，彻底清理再加 /ResetBase；打开图形清理界面可以直接输入 cleanmgr。Win7 只有 powercfg 和 cleanmgr 两条可用，DISM 组件清理请改用磁盘清理完成。

### C. 五个常见问题

清理后空间没变，多半是清理项需要重启才释放，或者是硬链接让预估数字偏大；存储感知显示的可清理量比实际少，因为它只统计自己管辖的类别；磁盘清理里看不到「Windows 更新清理」，通常是系统还没装过更新，或该补丁尚未安装；搬移用户文件夹后桌面图标消失，去 D 盘目标目录找回即可，快捷方式需要重建；C 盘长期低于 5GB 时，Windows 更新可能直接失败，这时优先做第四轮和第五轮。
